Este repositorio contiene el proyecto práctico desarrollado a lo largo del curso profesional para dominar la implementación de **Clean Architecture** en el ecosistema **.NET 9**, aplicando patrones de diseño modernos, buenas prácticas de la industria y aseguramiento de calidad mediante pruebas unitarias.

## 🚀 Lo que Aprenderás e Implementarás

* **Estructura del Proyecto:** Crear una solución limpia organizada por capas independientes en .NET 9.
* **Principios SOLID:** Aplicación rigurosa de principios de diseño orientado a objetos en todas las capas.
* **Domain-Driven Design (DDD):** Enfoque práctico para el modelado del dominio de la aplicación (Entidades, Agregados, Objetos de Valor).
* **CQRS y MediatR:** Separación limpia de operaciones de lectura (Queries) y escritura (Commands) para maximizar la escalabilidad.
* **Persistencia:** Configuración avanzada de Entity Framework Core, patron Repositorio y gestión de migraciones.
* **Validación:** Implementación de validaciones desacopladas e instructivas con FluentValidation.
* **Pruebas Unitarias:** Creación de baterías de test eficaces para blindar los casos de uso y lógica de negocio.
* **Producción:** Organización óptima de carpetas, inversión de dependencias y preparación para entornos reales de producción.

---

## 🏗️ Arquitectura del Proyecto

La solución sigue los principios de **Clean Architecture**, aislando la lógica de negocio central de los detalles de infraestructura, bases de datos e interfaces de usuario.
